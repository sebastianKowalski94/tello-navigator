# Tools

## map_parser — Map Statistics Parser (C++)

A C++ utility that reads the PNG map generated by `grid_map.py` and prints
detailed statistics: cell counts, coverage percentage, area in m², and an
ASCII preview of the map.

### Compile

```bash
g++ -std=c++17 -O2 -o map_parser tools/map_parser.cpp
```

### Usage

```bash
# Default — reads docs/final_map.png, 25cm cell size
./map_parser

# Custom map file
./map_parser /home/pi/tello_data/final_map_20250516.png

# Custom map file + cell size
./map_parser /home/pi/tello_data/final_map_20250516.png 25
```

### Notes

- Requires Python 3 + Pillow for PNG → PPM conversion (already installed if
  you followed the main setup guide)
- Colour thresholds match exactly the palette used in `mapping/grid_map.py`
